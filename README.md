# Age Group Attendance Management System

## Description

This project is a Python-based attendance management system that collects a person's name, phone number, and age. It classifies each person into one of three age groups: Child, Adult, or Old.

## Age Groups

- Child: 0–18 years
- Adult: 19–69 years
- Old: 70–110 years
- Invalid: Ages below 0 or above 110

## Features

- Collects attendance information from users
- Classifies people according to age
- Validates age input
- Handles invalid age entries
- Stores attendance records in separate lists
- Displays a final attendance summary

## Files

- `age_group_attendance.ipynb` — Python notebook containing the complete program

## Example Result

The program was tested with five attendance records:

- 1 Child
- 2 Adults
- 2 Old people

The program correctly classified all five records.
